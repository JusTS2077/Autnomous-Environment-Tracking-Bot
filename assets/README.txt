ASSETS DIRECTORY FOR MARS ROVER & GRID CELL IMAGES
===================================================

You can place your custom PNG image files in this folder (`assets/`).
The application (main.py) will automatically detect and load them!

SUPPORTED IMAGE FILENAMES:
--------------------------
1. rover.png     - Custom image/sprite for the Mars Rover Agent
2. battery.png   - Custom image for Solar Recharge Stations (Pods)
3. hazard.png    - Custom image for Hazard Craters
4. radiation.png - Custom image for Radiation Anomaly cells
5. storm.png     - Custom image for Dust Storm cells
6. start.png     - Custom image for Start Station (S)
7. goal.png      - Custom image for Goal Habitat (G)
8. safe.png      - Custom image for Discovered Safe Soil cells

NOTE:
If any image is missing, the application will automatically fall back
to clean procedural visual styling, so all files are optional!
